## Overview

**Traceri** is an interactive digital life archive, editorial magazine, and empirical data archaeology. Rather than treating personal history as isolated metrics or unsearchable log files, Traceri connects everyday receipts, train tickets, coffee stops, exhibitions, and late-night walks into coherent emotional and temporal narratives.

- **Production URL**: [https://traceri.vercel.app](https://traceri.vercel.app)
- **Source Code**: [https://github.com/Ankit628792/Traceri](https://github.com/Ankit628792/Traceri)

## The Core Experiences

| Route | View | Description |
| :--- | :--- | :--- |
| `/` | **Primary Archive** | Master stream of chronological digital receipts, itemized artifacts, and category filters. |
| `/threads` | **Recurrent Threads** | Connected behavioral sequences and recurring rituals woven across time. |
| `/story` | **Narrative Monograph** | Curated long-form editorial essays and thematic chapters on memory and place. |
| `/calendar` | **Temporal Matrix** | Heatmaps and temporal densities revealing daily rhythms, weekly habits, and seasons. |
| `/atlas` | **Spatial Atlas** | 3D celestial globe and geographic cartography anchoring memories to coordinates. |
| `/discoveries` | **Synthesis & Insights** | Algorithmic reflections, categorical spending splits, and life correlations. |

For an in-depth non-technical exploration of the creative vision and each route, consult **[INFO.md](INFO.md)**.

## Key Highlights

- **Editorial Aesthetic**: Warm obsidian canvas (`#0A0B0D`), Newsreader serif headings, JetBrains Mono metadata numerals, and warm gold accents (`#CFA04E`).
- **Integrated Datasets**: Provided **Daily Household Transactions** (itemized receipts, category taxonomies, merchant metadata) and **spotify_data_dictionary** (cultural audio logs, listening timestamps, and emotional vibe mapping).
- **Interactive 3D Cartography**: Interactive Three.js spatial globe visualizing geographic coordinates and location clusters.
- **Fluid Layout Transitions**: Motion-driven page changes and layout transitions without jarring page resets.
- **Client-Side SEO & Manifest**: Dynamic `<meta>`, OpenGraph cards, Twitter cards, and Schema.org JSON-LD structured data synchronized across routes.
- **Clean URLs**: Clean browser history without hash fragments, backed by SPA fallback rewrites.

## Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/Ankit628792/Traceri.git
cd Traceri

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

For complete environment configuration, build verification, and deployment instructions, see **[SETUP.md](SETUP.md)**.
